## Задание

1. Для данного отрезка $[a, b]$, весовой функции $\rho$ и числа $n$ построить квадратурную формулу (формула А) указанного типа с $n+1$ узлами для приближенного вычисления интеграла вида $\int\limits_a^b f(x)\rho(x)\, dx$. Указать $m$ - АСТ построенной квадратурной формулы.
2. Выписать формулу для остатка построенной КФ.
3. Сравнить точность построенной формулы с формулой Б - аналогичной по трудоемкости формулой типа Ньютона-Котеса (по равноотстоящим узлам, но с весовой функцией $\rho$). Сравнение провести для следующих типов подынтегральных функций $f$:
	- многочленов степени $n, n+1, m, m +1$ ($m$ - АСТ первой построенной КФ),
	- гладкая функция (отличная от многчлена),
	- функция, имеющая разрыв первой производной внутри отрезка интегрирования.

Содержание отчета:
- подробное описание построения формул НАСТ и Ньютона-Котеса, их АСТ;
- полученный узлы и квадратурные коэффициенты для обеих формул;
- таблица вида;

| f   | Точное значение интеграла | Погрешность ф. А | Погрешность ф. Б |
| --- | ------------------------- | ---------------- | ---------------- |
|     |                           |                  |                  |
- объяснение полученных результатов, код программы.
